Specialized Agent Roles

Every agent in the swarm specializes in a strict domain:

  • TriageSupervisorAgent: Ingests CloudWatch alarms & dispatches tasks.
  • TelephonyVoiceAgent: Drives AWS Chime PSTN calls & parses speech.
  • DevOpsRemediationAgent: Orchestrates ECS task definitions & canary drains.
  • IncidentReporterAgent: Synthesizes Markdown post-mortems.
